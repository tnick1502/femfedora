# Инженерный аудит EMO Core — 13 ноября 2026

Проверена рабочая копия после голосового дополнения, управления распознавателями и диагностики промптов. Исходный коммит — 4a97e11; последующие изменения локальные. Проверка охватила голосовой HTTP-путь, обработку чата, стейт/память, ограничения контекста, согласия, снимки промптов, retention, браузер и миграции. Сервер и рабочая БД не обновлялись.

## Измерения расхода

Синтетическая фикстура: 100 сообщений с диагностическим полем 8192 байта каждое. Полный ответ страницы — 870534 байта; ответ неизменившегося polling — 152 байта, сокращение 99.983%. Это размер HTTP body в данном сценарии, не обещание экономии на реальном трафике. История для модели в этом сценарии — 24500 байт JSON без диагностических полей; отдельный тест проверяет их отсутствие в SELECT.

Для 100 синтетических реплик по 8000 символов исходный запрос резюме оценивался в 286888 токенов. Выбранный полный префикс из четырёх реплик — 11779 при лимите 12000. Все 100 исходных сообщений сохраняются; не вошедшие в свёртку не помечаются пересказанными. Оценка токенов приближённая, по существующему коэффициенту 2.8 символа/токен, не биллинг провайдера.

## Что ограничивает запуск с реальными пациентками

Инженерные исправления не снимают фактические продуктовые блокировки. Встроенные safety policy и протоколы всё ещё ожидают документированного клинического утверждения; приложение намеренно запрещает production без него. Клиническая чувствительность JEV/gate, качество ASR и определение эмоций не валидированы на реальных пациентках. Этот аудит не менял флаги на approved и не пересматривал медицинские пороги.

Это один процесс API с PostgreSQL и существующим worker. Лимиты одновременности умножаются при горизонтальном масштабировании; долговечные квоты остаются общими через БД. Точное at-most-once списание внешнего API при падении между ответом поставщика и записью квитанции не гарантируется. Отмена нативного inference не останавливает CPU немедленно, но исключает накопление заданий. Регион/условия хранения у внешних поставщиков и удаление из резервных копий контролирует оператор.

Онлайн-проверка уязвимостей зависимостей не завершена: OSV ответил тайм-аутом TLS, альтернативные запросы к PyPI также недоступны. Проверенных пакетов 0 из 53, поэтому отсутствие предупреждений не считается чистым результатом. Версии не обновлялись вслепую; эту проверку нужно повторить при доступности источников. Сканирование нативных библиотек контейнера в этот результат не входит.

Нагрузочный soak-тест на целевом сервере не выполнялся. На сервере остаётся прежняя версия; для этой поставки нужны новые миграции и перезапуск API/worker. Commit, push и deploy в данном проходе не выполнялись.
