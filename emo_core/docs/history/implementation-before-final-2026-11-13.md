## Дополнительные требования пользователя

- Отчёт решения хранится с ответом: Jev, причины, потребность, протокол, модели, ревизия, проверки и время. В stdout полный отчёт не выводится.
- Администратор управляет общими профилями LLM/Jev и режимом для следующих сообщений всех пользователей. Ключи хранятся в `.env` по ссылкам либо зашифрованы в БД; аудит не содержит их значений.
- Механизм шкал доступен через REST API. Вопросы, ключи и методы оценки сохранены отдельно; результаты считает Python.
- Есть личные настройки маскирования, контроль контекста, журнал состояния, календарное обновление перинатального контекста и различение ручной/автоматической паузы.
