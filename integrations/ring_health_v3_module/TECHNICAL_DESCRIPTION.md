# TECHNICAL_DESCRIPTION — модели Ring Health v3

Версия `ring-health-v3.0.0`. Полный исследовательский отчёт с источниками и всеми таблицами: `reports/ring_health_v3_report_ru.md`. Метрики в JSON: `reports/experiments/`. Реестр всех 74 параметров генератора с источниками: `reports/experiments/parameter_registry.json`.

## 1. Архитектура

```
request JSON ──► schema.py (pydantic, строгая проверка) ──► engine.py (RingHealthV3)
                                                 │
            ┌────────────────────────────────────┴───────────────────────────────┐
            ▼                                                                      ▼
  fertility.py  ◄── cycle_engine.py (байесовская модель цикла)          menopause.py ◄── menopause_features.py
  фаза, окно, овуляция, месячные, история                                стадия, FMP 6–60 мес, приливы
  параметры: models/.../cycle_engine_params.json                          модели: menopause_models.joblib (HGB)
                                                                          + menopause_vms_night.joblib (модель ночи)
```

| `sim_cycles.py`, `sim_menopause.py`, `params.py` | Генераторы синтетики и реестр параметров (нужны для обучения; `sim_menopause.STAGES` используется в рантайме) |
| `train_cycle.py`, `train_menopause.py`, `eval_cycle.py`, `metrics_cycle.py`, `real_benchmarks.py`, `nhanes_anm.py` | Обучение и оценка (`scripts/train_ring_health_v3.py`) |

## 2. Модуль цикла: модель

**Скрытая переменная** — день овуляции O текущего цикла (сетка 6…max(45, t+20)) плюс гипотеза «ановуляторный цикл».

**Модель наблюдений** для сигнала s ∈ {температура, мин. ЧСС, ln RMSSD, частота дыхания} в ночь t:

y_s(t) = μ_c + a_s · g_s(t − O) · e_s(дней до следующих месячных) + ε_s(t)

- ε — стационарный AR(1). Ковариация ρ^|Δt| считается по реальным датам наблюдённых ночей, поэтому **пропуск ночи не заполняется**: ночь просто отсутствует в векторе наблюдений. Тест сверяет результат с прямым многомерным нормальным распределением до 1e-6.
- Смещение цикла μ_c ~ N(база, τ²) и амплитуда a_s ~ N(m, v) интегрируются аналитически: лемма об определителе и формула Шермана–Моррисона. Одна факторизация Холецкого на цикл и сигнал; все кандидаты O за O(n·|O|).
- Шаблоны g_s (k = −20…25 дней от овуляции) и предменструальный спад e_s оценены регрессией с фиксированными эффектами цикла на 300 синтетических женщинах (3 900 циклов). Амплитуды и шумы — там же. Коэффициент λ = 0,7 (мягкое правдоподобие) выбран на валидации.

**Априор O** — личный: фолликулярная фаза ~ N(μ_F,i, σ_F,i). Оценка эмпирическим Байесом по прошлым циклам (апостериорные E[O], Var[O], P(овуляторный)) со сжатием к реальным популяционным априорам FedCycleData:
- фолликулярная фаза 16,0 дня, межличностное SD 2,8, внутриличностное 2,3;
- возрастной наклон −0,14 дня/год;
- лютеиновая фаза 12,8 (SD 1,5 / 1,3).

Так же персонализируются лютеиновая фаза, амплитуды сигналов (иерархическая нормальная модель) и частота ановуляции (Beta с априором по возрасту: 7 / 7 / 10 / 15 / 25% для 20 / 35 / 40 / 45 / 55 лет).

**Дополнительные свидетельства:**
- завершённый цикл — правдоподобие лютеиновой фазы p_L(длина − O);
- текущий цикл — «месячных ещё нет» с учётом неполного логирования: P = S_L(t − O) + (1 − S_L)·q, где q = 0,1 или 0,03 при полных логах;
- LH-тесты — P(+ | смещение) = 0,4 / 0,9 / 0,5 для −2 / −1 / 0, ложноположительные 2%.

**Чистка данных (единые маски на весь запрос):**
- ночи с вероятной лихорадкой (скачок температуры > 0,75 °C от медианы 21 дня с ростом ЧСС > 5, или > 1,1 °C) исключаются;
- первые дни после залогированного начала исключаются для ЧСС и HRV (дни 1–3) и для температуры и дыхания (день 1);
- глобальные выбросы: > 5σ + амплитуда.

**Незалогированные месячные.** Если сегмент длиннее ожидаемого (μ + max(6, 2σ), ≥ 30 дней, ≤ 100 дней), сравниваются маргинальные правдоподобия «один цикл» и «цикл до N + новый с N» для всех N. Ночи и маски одни и те же, априор не перенормируется, добавляется log q. При P(разбиение) ≥ 0,8 возвращается подсказка подтвердить дату. Сегменты длиннее 100 дней дают `anchor_stale`.

**Решения (пороги выбраны на валидации заранее заданным правилом: максимум попаданий ±2 дня при ≤ 10% ложных на ановуляторных):**
- фертильный день: P(O ∈ [t, t+5]) ≥ 0,25;
- подтверждение в реальном времени: P(O ≤ t−2) ≥ 0,99, масса лучших 3 дней ≥ 0,5, ≥ 3 ночей температуры после O, последняя температура ≤ 5 дней назад;
- история: P(овуляторный) ≥ 0,9, концентрация ≥ 0,4, ≥ 8 ночей сигналов и ≥ 3 ночей до и после оценки;
- следующие месячные: смесь по O распределения O + L + 1, условного на «ещё не начались», 80% интервал;
- фаза: по `cycle_day`, длительности менструации, окну и статусу овуляции.

**Проверено и отвергнуто:** градиентный бустинг поверх апостериорных признаков (AUROC 0,901 против 0,913, Brier хуже).

## 3. Модуль менопаузы: модель

**Признаки** (одинаковые в обучении и рантайме, `menopause_features.py`):
- возраст (целый);
- кровотечения: дни с последних месячных (max из логов и даты онбординга), число месячных за 6 и 12 мес (0 при ведении логов), медиана, SD, максимум и последний интервал, интервалы ≥ 60 дней, стойкие разницы ≥ 7 дней в последних 10 интервалах, длительность ведения логов;
- кольцо (последние 90–365 ночей):
  - доля овуляторных циклов по модели цикла и средний температурный сдвиг;
  - сила периодичности температуры 21–40 дней (периодограмма МНК по наблюдённым ночам);
  - ночная вариабельность температуры и доля температурных всплесков среди наблюдённых ночей;
  - индекс приливов (модель ночи) и доля ночей с приливом;
  - эффективность сна, время бодрствования, сон;
  - ln HRV относительно возрастной нормы, ЧСС;
- самоотчёт: дни с приливами или потливостью за 30 дней (если дневник ведётся);
- при наличии: ln ФСГ, ln АМГ, курение, ИМТ, роды, высшее образование.

Индикаторов пропуска нет. Обучение со случайным, независимым от исхода скрытием входов: логи 85%, дата онбординга 75%, кольцо 92%, ФСГ 25%, АМГ 15%, ковариаты 60%.

**Модели** — HistGradientBoosting (sklearn 1.9.1):
- стадия, 4 класса;
- 6 бинарных моделей «FMP случилась или случится в течение h месяцев», h = 6, 12, 24, 36, 48, 60, с монотонизацией по h; медиана — интерполяция по кривой;
- наборы признаков `full`, `age_bleeding`, `age_ring`, `age_only` (логистика по возрасту);
- **маршрутизация** по доступным входам выбрана на валидации: labs → full, bleeding+ring → full, только bleeding → age_bleeding, только ring → full, ничего → full.

**Правило STRAW+10:** ≥ 365 дней без месячных и надёжный источник (дата онбординга или полные / ≥ 400 дней логи) → постменопауза, FMP подтверждена. Флаги «интервал ≥ 60 дней» и «стойкая разница ≥ 7 дней» выставляются при логах ≥ 180 дней.

**Модель ночи (приливы)** — HGB по отклонениям ночи от личной 30-дневной медианы: температура, эффективность, бодрствование, ln HRV, ЧСС, дыхание, сон и превышение 7-дневного минимума температуры.

## 4. Обучающие данные

Открытого набора «ночи кольца + LH/гормоны + исходы» нет. Модели обучены на синтетике из физиологических генераторов; реальные данные использованы для параметров, калибровки и проверки.

**Цикл** (`sim_cycles.py`):
- иерархические фазы по реальным FedCycleData (1 499 циклов, 157 женщин);
- кривые прогестерона и эстрадиола → температура, ЧСС, HRV, дыхание с величинами Oura, Ava, WHOOP;
- лихорадка, алкоголь, перелёты, выбросы, дрейф;
- реалистичная носка (3 профиля, эпизоды и длинные перерывы, выпадение каналов) и логирование (пропуски 0/10/25%, сдвиг ±1–2 дня).

Калибровка к Oura (Maijala 2019): разница фаз 0,31 ± 0,13 против 0,30 ± 0,12 °C; ночной SD 0,215 против 0,20 ± 0,07 °C.

**Переход** (`sim_menopause.py`):
- возраст FMP — реальная кривая Каплана–Мейера NHANES 2015–2018 (2 554 женщины), ранний хвост пересчитан на InterLACE; ковариаты из NHANES-модели;
- длительности стадий — Paramsothy 2017;
- доля овуляторных циклов — Santoro 2017;
- ФСГ — Randolph 2011;
- АМГ откалиброван к таблице Finkelstein 2020: MAE 0,054, r = 0,93;
- приливы — 4 траектории SWAN (Tepper 2016), величины de Zambotti 2013.

Точки наблюдения — популяционный срез 38–62 лет.

**Объёмы:**
- цикл: обучение 300 женщин × 13 циклов; валидация 100 + 60 с повышенной ановуляцией; тест 250 + 80 + 80 + 100 и 40 в парных стрессах;
- менопауза: обучение 3 000 × 4 точки; валидация 700 × 4; тест 1 000 × 3 в каждом из 7 режимов входов;
- все наборы разведены по seed, люди не пересекаются.

## 6. Независимая проверка

Отдельный рецензент подтвердил: утечек истины во входы нет, разбиения не пересекаются, правдоподобие сходится с прямым расчётом. Найденные им 8 серьёзных и 11 мелких дефектов исправлены, на ключевые добавлены тесты. Список — в `reports/ring_health_v3_report_ru.md`, раздел «Независимая проверка».

## 7. Ограничения

1. Нет реальной парной когорты «кольцо + LH/УЗИ + исходы». Метрики показывают, как модель восстанавливает заложенную физиологию при реалистичных шуме и пропусках; это не клиническая точность.
2. Вклад приливов в ночные агрегаты Oura, эффекты HRV и дыхания, модель пропусков — допущения из реестра параметров.
3. FMP-модель не проверялась на реальных продольных данных (SWAN ICPSR — следующий шаг).
4. Гормональная терапия, контрацепция, беременность, хирургическая менопауза, ранняя недостаточность яичников — вне области (`out_of_scope`).

## 8. Как переобучить или откалибровать под новое кольцо

```bash
pip install -r requirements-training.txt
python scripts/train_ring_health_v3.py cycle       # шаблоны/шумы, валидация порогов, тест
python scripts/train_ring_health_v3.py real        # FedCycleData, TempID (нужны data/external/...)
python scripts/train_ring_health_v3.py menopause   # NHANES, генератор, модели, маршрутизация, тест
python scripts/train_ring_health_v3.py paired      # парные стресс-сценарии
```

Скрипты обучения ожидают структуру репозитория femfedora: реальные данные в `data/external/ring_health/`. В модуле лежат только рантайм-артефакты.

Под новое кольцо (Sber) с реальными размеченными циклами (LH-эталон): заменить в `cycle_engine_params.json` шаблоны, амплитуды и шумы. Их оценка — `train_cycle.fit_templates` и `fit_amplitude_noise` на реальных ночах с известной датой овуляции. Пороги переподобрать на отложенных женщинах тем же правилом.
