# demo_users — 10 тестовых пользовательниц для демонстрации модуля

Синтетические, но реалистичные пользовательницы. Физиология получена из генератора v3. Поведение задано по сценарию: как носят кольцо, как и что отмечают, какой профиль, анализы, формат Oura. Все даты приведены к `as_of = 2026-11-09`. Реальных людей здесь нет.

## Структура папки каждой пользовательницы

| Файл | Назначение | Отправлять в API? |
|---|---|---|
| `input.json` | Готовый request для `RingHealthV3().analyze()` / `POST /v3/analyze` | **да** |
| `output.json` | Ответ модуля (эталон для сверки и для заглушек UI) | нет, это ответ |
| `persona.md` | Описание пользовательницы и что показывать на демо | нет |
| `persona.json` | То же в машинном виде (имя, возраст, цель, поведение, профиль) | нет |
| `_ground_truth_for_qa.json` | Скрытая «истина» генератора: настоящая дата овуляции, стадия, время до менопаузы | **никогда** — только для QA |

## Что демонстрирует каждая

- **01 Анна:** идеальный сценарий фертильности. Сегодня в окне, овуляция ожидается завтра; LH-тесты.
- **02 Мария:** длинные циклы. Овуляция подтверждена по физиологии на 7-й день после неё, сейчас лютеиновая фаза; кольцо снимает на зарядку.
- **03 Екатерина:** данные в формате **Oura API**. Забыла отметить месячные — модуль сам предлагает «Похоже, месячные начались 01.11 — подтвердить?».
- **04 Дарья:** новая пользовательница, 12 ночей и одна дата. Прогноз есть, доверие `medium`.
- **05 Ольга:** болела 3 ночи назад, скачок температуры и пульса. Ночи помечены как болезнь и исключены, окно не сломалось.
- **06 Ирина, 41:** **оба модуля сразу**. Цикл (овуляция, вероятно, прошла) + стадия «репродуктивный период», FMP в течение года ≈ 0.
- **07 Елена, 46:** менопаузальный трекинг. **Поздний переход**, вероятность FMP в течение 12 мес ≈ 0,43, медиана ~14 мес; 20 дней приливов по дневнику; критерии STRAW (интервал ≥ 60 дней, стойкая разница циклов) выполнены.
- **08 Наталья, 49:** не ведёт календарь — только дата последних месячных из онбординга + ФСГ + курение. Поздний переход.
- **09 Светлана, 53:** **постменопауза** — 12+ месяцев без менструаций (детерминированное правило STRAW+10), приливы почти каждый день.
- **10 Татьяна, 31:** скудные данные: кольцо ~60% ночей с перерывом больше недели, месячные отмечает через раз, профиль пустой. Прогноз с пониженным доверием.

## Как использовать агенту

1. Для демо-экрана загрузить `input.json` нужной пользовательницы как «тестового пользователя», вызвать модуль, отрисовать ответ. Он должен совпасть с `output.json`.
2. Для вёрстки без бэкенда использовать `output.json` как фикстуру (типы в `../types/ring_health_v3.ts`).
3. Проверка: `python scripts/run_demo.py` из корня модуля → `26 identical, 0 different`.
4. Даты в данных зафиксированы на 9 ноября 2026. Чтобы «жить» в другой день, сдвиньте все даты в `input.json` на одинаковое число дней (`as_of`, `nights[].date`, `period_starts`, LH, симптомы, анализы). Ответ сдвинется так же.
