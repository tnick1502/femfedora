# Когорта CDC для исследования записанного HDP-proxy

`eligible_all_2023_2024.parquet` — 6 763 850 одноплодных живорождений резиденток США с известной меткой `target_hdp_proxy` и `RF_PHYPE=0`. Это производный файл из CDC Natality, **не отдельная клиническая база преэклампсии**. `audit.json` содержит годовые объёмы, определения, SHA-256 и исключения; `folds_all.csv`, `missingness_by_year.csv`, `input_masks_by_year.csv` — проверки подготовленной когорты. `feature_analysis_sample.parquet` — уменьшенная выборка для анализа признаков, не замена полной когорте.

Поля: `source_year` + `source_row` — ключ к исходной записи; `fold` — один из пяти исследовательских фолдов; `target_hdp_proxy` — `RF_GHYPE=Y` или `RF_EHYPE=Y`; `target_hdp_preterm37`/`target_hdp_preterm34` — составные исходы с родами до 37/34 недель. `mager`, `bmi`, `priorlive`, `priordead`, `priorterm`, `rf_pdiab`, `rf_ppterm`, `rf_cesar` — основной анамнез/факторы; `mrace6`, `mhisp_r`, `meduc` и ART-поля — анализ чувствительности. `bmi_missing`, `prior_live_birth_count_missing`, `priorterm_missing`, `core_scoring_ready`, `art_source_reported`, `art_status_unknown_reported` — маски качества и маршрута данных; `age_35_plus`, `bmi_30_plus`, `bmi_35_plus`, `no_prior_live_birth` — производные аудитные категории.

Используется для методологического сравнения моделей по записанной метке и временной проверки 2023→2024. `rf_ghype`, `rf_ehype`, `oegest_comb` и производные метки нельзя подавать в вход модели. Фолды не могут группировать повторные беременности одной женщины: публичный ID матери отсутствует. Полный протокол и запреты: [`research/reports/preeclampsia_cdc_hdp_proxy.md`](../../../research/reports/preeclampsia_cdc_hdp_proxy.md) и [`MODEL_INPUT_CONTRACT.md`](../../../research/notebooks/preeclampsia_cdc/MODEL_INPUT_CONTRACT.md).
