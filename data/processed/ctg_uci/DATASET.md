# Подготовка UCI Cardiotocography · ноутбук 01

Все файлы в этом каталоге создаёт `research/notebooks/ctg_uci/01_prepare_data.ipynb` из официального `CTG.xls`. Сам набор лицензирован CC BY 4.0; источник и контрольный хэш указаны в `manifest.json` и в реестре проекта.

| Файл | Содержимое |
|---|---|
| `ctg_primary.parquet` | 2126 строк сегментов, 21 неизменённый признак, обе экспертные метки, номер строки XLS и метаданные записи. Пропуски, если они возникнут в будущем источнике, сохраняются. |
| `ctg_splits.parquet` | Одно фиксированное разбиение train / validation / test: 1360 / 341 / 425 строк. Доли каждого класса `NSP` и `CLASS` отличаются от полного набора менее чем на 0,4 процентного пункта. Поля меток, `source_file` и группа повторов сохраняются для проверки. |
| `train_sample_weights.parquet` | Веса классов `NSP` только для train; их суммарный вес одинаков по трём классам. Validation и test не пересэмплируются. |
| `X_train.parquet`, `X_validation.parquet`, `X_test.parquet` | Матрицы из 23 модельных признаков и `source_excel_row` для соединения с метками. Меток внутри X нет. |
| `preprocessor.joblib` | Проверка входных данных, раздельные преобразования, скейлеры и one-hot `Tendency`; параметры оценены только на train. |
| `scalers.joblib`, `scaler_parameters.json` | Отдельно сохранённые обученные скейлеры и их параметры в читаемом виде. Порядок применения задан `preprocessor.joblib`. |
| `manifest.json` | Путь и хэш источника, роли полей, правила пропусков и исключений, параметры разбиения и состав модельных признаков. |

В `ctg_primary.parquet` поля `source_excel_row`, `source_file`, `segment_file`, `recorded_date`, `feature_duplicate_group` служат только для происхождения и контроля разбиения. `NSP` и `CLASS` — метки. Не передавайте эти семь полей в модель как признаки.

Разбиение по `source_file` удерживает все сегменты одной исходной записи вместе. Фолды выбираются по близости распределений обеих экспертных меток; проверка ноутбука также подтверждает, что идентичные векторы признаков не пересекают части. Естественный дисбаланс классов в test сохранён для честной оценки. Идентификатора пациентки нет; эти выборки не являются независимой клинической когортой.

В данном снимке нет пропусков ни в одном признаке. Поэтому маски пропусков были бы постоянными нулями, а импутация не имела бы наблюдаемой базы для проверки. Сохранённый преобразователь отклоняет новый пропуск и неизвестный код; для другого источника потребуется отдельная оценка пропусков и переобучение. `DS` сохранён в `ctg_primary.parquet`, но исключён из матриц: ненулевые значения встречаются лишь в 7 сегментах двух исходных файлов train. Его эффект невозможно надёжно оценить на этом разбиении. `Width` также остаётся в первичной таблице, но исключён из масштабированной матрицы, поскольку точно равен `Max − Min`.
