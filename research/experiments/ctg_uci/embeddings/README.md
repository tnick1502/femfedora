# Дополнение: сжатие и кластеризация КТГ

Выполняемый отчёт — [ноутбук 06](../../../notebooks/ctg_uci/06_clustering_embeddings_grid_search.ipynb). Предыдущие результаты 04 сохранены в родительской папке; их SHA-256 фиксирует `preserved_legacy.json`. Подробный протокол — в `research/notebooks/ctg_uci/EXPERIMENT_PLAN.md`.

## Сетка и границы интерпретации

55 представлений: UMAP 27, undercomplete denoising AE 24, PCA 3, без сжатия 1. Для каждого — 30 сочетаний FCM/KMeans/GMM, всего 1650. Выбор по validation silhouette в общем пространстве признаков, усреднённому по исходным файлам, с проверками сходимости, размера кластеров и trustworthiness. NSP и CLASS не используются в подборе. Все преобразования обучаются только на train; для AE early stopping имеет отдельное разбиение по файлам внутри train и собственные внутренние скейлеры.

Это исследовательское продолжение на известном benchmark, а не независимая слепая когорта. Связь с NSP рассматривается после фиксации параметров. Метка NSP — экспертная интерпретация КТГ, не наблюдаемый перинатальный исход. Принадлежности FCM/GMM не являются вероятностями патологии. Интервалы обогащения точечные, без поправки на множественные сравнения. Проверка устойчивости описывает чувствительность к seed и пяти подвыборкам файлов, не доверительный интервал качества будущей модели.

## Наблюдаемые результаты

Выполнены все 1650 сочетаний и 84 повторных обучения для диагностики чувствительности. Для FCM test ARI с NSP: прежний PCA90 из 04 — 0.0741, новый контроль без сжатия — 0.0764, новый PCA — 0.0483, UMAP — −0.0104, AE — 0.0641. Все выбранные решения имеют k=2. UMAP+FCM выбрал 5 компонент, 30 соседей, min_dist=.1; AE+FCM — 2 компоненты, ширину 16, ReLU, alpha=.001 и 842 эпохи.

AE+GMM: 5 компонент, ширина 16, ReLU, alpha=.1, 624 эпохи, два компонента GMM с диагональными ковариациями. Test ARI 0.2159; 20/45 патологических сегментов в обогащённом кластере (44.4%) относятся всего к двум исходным файлам. Интервал обогащения 0–8.52 включает 1; ARI совпадения validation-назначений при двух дополнительных seed −0.010–0.075. Это неустойчивый исследовательский результат. Ни один выбранный кластер не имеет точечного интервала обогащения патологией целиком выше 1. Подтверждённое устойчивое улучшение от нелинейного сжатия не установлено.

## Применение сохранённого UMAP + FCM

Из корня проекта в окружении `poetry.lock`:

```python
import joblib

saved = joblib.load('models/exported/ctg_uci/clustering_embeddings.joblib')
model = next(b for b in saved['bundles'].values()
             if b['config']['method'] == 'UMAP' and b['config']['algorithm'] == 'FCM')
# new_features: DataFrame ровно с 21 исходным признаком, без NSP/CLASS/метаданных.
common = saved['input_model'].transform(new_features[saved['feature_columns']])
latent = model['reducer'].transform(common)
memberships = model['clusterer'].predict_proba(latent)
clusters = memberships.argmax(axis=1)
```

Номера кластеров условны и не соответствуют кодам NSP 1/2/3. Новые пропуски и нарушения входной схемы отклоняются; они не маскируются молча.
