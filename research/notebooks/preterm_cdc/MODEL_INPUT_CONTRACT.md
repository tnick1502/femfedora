# Контракт исследовательского прогноза CDC PTB

## Единица, популяция и исход

- Одна строка — **одно одноплодное живорождение** резидентки США (`RESTATUS ∈ {1,2,3}`, `DPLURAL=1`) с известным `OEGEST_COMB`. Запись не эквивалентна всем текущим беременностям.
- Исход основан на акушерской оценке срока **при родах** в завершённых неделях: класс 0 `<32`, класс 1 `32–33`, класс 2 `34–36`, класс 3 `≥37`.
- Все преждевременные роды вместе: причина/начало родов в подготовленной таблице не установлены. Включены самопроизвольные и медицински показанные роды. Мертворождения отсутствуют.
- Нет точной даты начала беременности, даты каждого обследования или ID матери. Базовая модель сама по себе не оценивает риск у продолжающейся беременности; ноутбук 06 добавляет **исследовательское приближение** условного распределения по неделям, описанное в [WOMAN_FORECAST_CONTRACT.md](WOMAN_FORECAST_CONTRACT.md).

## Разбиение и выбор

2023: стабильный псевдослучайный hash `source_row` с seed `20261004`: 60% train, 20% validation, 20% calibration. Фолды не используются. Кандидаты обучаются на одной фиксированной случайной подвыборке до 500 000 train и сравниваются на одной validation-подвыборке до 200 000 по многоклассовому log loss. Early stopping LightGBM/CatBoost использует только эту validation-подвыборку. Абляции и важность на той же validation-подвыборке исследовательские. Победитель переобучается на полном train+validation; температура вероятностей подбирается на полном calibration. Полный 2024 используется для итоговых метрик, не для выбора. Из-за отсутствия материнского ID повторные беременности одной женщины могут пересечь разбиения или годы.

## Основные входы

| Признак | Смысл и момент доступности |
| --- | --- |
| `maternal_age_at_birth` | Возраст в свидетельстве о рождении; только приближение возраста до исхода. |
| `prepregnancy_bmi` | BMI до беременности. |
| `previous_live_births` | `PRIORLIVE + PRIORDEAD`; оба поля относятся к предыдущим живорождениям. Если любое неизвестно, сумма неизвестна. |
| `previous_terminations` | `PRIORTERM`; суммарное число предыдущих завершений беременности, неоднородное по типу. |
| `previous_preterm_birth` | Отмеченный анамнез преждевременных родов, без точного срока и фенотипа. |
| `chronic_hypertension`, `preexisting_diabetes` | Состояния до беременности. |
| `previous_cesarean` | Предыдущее кесарево сечение. |
| `prepregnancy_cigarettes_per_day` | Самоотчёт о курении до беременности. |

Для каждого поля с возможным пропуском сохраняются значение `NaN` и явная маска `*_missing`. Это воспроизводит пропуски свидетельства о рождении, но не означает, что незаполненный пункт новой анкеты имеет тот же смысл. Поэтому индивидуальный `predict_woman` отказывается выдавать вероятность, если любое модельное поле неизвестно. Логистика заполняет пропуск медианой, рассчитанной только по её обучающим строкам. LightGBM и CatBoost получают ту же матрицу с `NaN` и масками. Социальные и расовые коды не входят в основную модель; `mrace6` и `meduc` доступны лишь в подготовленном файле для последующего аудита.

## Запреты и границы утверждений

В модель не входят `OEGEST_COMB`, класс исхода, вес/пол ребёнка, диагнозы и вмешательства текущей беременности, фактическое число дородовых визитов, текущий способ родов, `source_row`, `source_year` или аудиторские демографические поля. Многоплодные записи исключены до обучения; для них нужен отдельный дизайн на уровне беременности.

Это **offline baseline** по американским свидетельствам о живорождении. Его калибровка относится к такой же записи, а не ко всем женщинам с продолжающейся беременностью. Ноутбук 06 проверяет условное приближение на другой год того же источника и отдельно пересчитывает метрики на записях, допустимых индивидуальным контрактом. Возраст при родах в CDC не равен возрасту на предполагаемую дату родов при вводе; точность для такого расхождения неизвестна. В [исследовании NCHS двух штатов](https://www.cdc.gov/nchs/data/nvsr/nvsr62/nvsr62_02.pdf) чувствительность поля о предыдущих преждевременных родах была низкой, поэтому измерение ключевого анамнеза в новой среде может отличаться. Для персональной недельной вероятности на другой популяции нужны данные с датированными визитами, точным сроком в днях, типом начала родов, вмешательствами, исходами без живорождения и внешняя проверка.
